# Advanced Java

A collection of Java programs covering advanced topics including Collections, Stream API, Exception Handling, Regular Expressions, JUnit Testing, Annotations, and Real-world Scenarios.

## Prerequisites

- Java 8+ (or 11+)
- Any IDE (IntelliJ IDEA / Eclipse / VS Code)

## How to Run

Compile and run any Java file using the standard JDK tools:

```bash
javac <path/to/File.java>
java -cp <path/to/classes> <ClassName>
```

Example:

```bash
javac 1_Collections/Beginner/_CountNamesStartingWithChar.java
java -cp 1_Collections/Beginner CountNamesStartingWithChar
```

## Topics Covered

- **Collections** - List, Set, Map operations, comparators, and custom data structures
- **Stream API** - Filtering, mapping, reducing, grouping, and parallel streams
- **Exception Handling** - Try-catch-finally, custom exceptions, and best practices
- **Regular Expressions** - Pattern matching, validation, and text processing
- **JUnit Testing** - Unit tests, assertions, test lifecycles, and parameterized tests
- **Annotations** - Built-in and custom annotations, retention policies
- **Real-world Scenarios** - Problem-solving exercises and domain-specific implementations

## Contributing / Notes

All source files are organized by topic and difficulty level (Beginner → Intermediate → Advanced/Expert) to support progressive learning. Each module contains practical examples and scenario-based exercises.
